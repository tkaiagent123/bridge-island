    AI usage disclosure¶

    This project was developed with an AI coding assistant. This page records what was used, where, and the state of the author's review. The author, Tzvi Kaminsky, directs the work and is responsible for its content.

    Tools and models¶

    Item Name and version Provider
    Coding agent Claude Code 2.1.311 (command-line) Anthropic
    Language model Claude Sonnet 5.5 (model ID claude-sonnet-5-5) Anthropic
    Web search and page fetch The tools built into Claude Code, used only to look up public references Anthropic

    No other AI tool or model was used. Dates of use: 2026-10-25 to 2026-10-27. The agent ran on the author's machine, wrote files in the repository, ran the tests and linters, and created the git commits under the author's git identity.

    What came from the author, and what from the assistant¶

    From the author, not generated: the bridge/island architecture, its vocabulary, the six design guidelines (G1 to G6), the choice of examples and experiments, and every decision recorded in the review column below.

    Generated by the assistant: the Python implementation, the tests, the documentation text, the build and CI configuration, and the choice of every invented name, field, rate and number in the examples. No code or text was copied from another project. The public references in docs/related-work.md were looked up against their public pages by the assistant using web search and fetch; the author has not yet verified them independently.

    Author decisions recorded so far¶

    • 2026-10-27: the rate policy is offered as two options (cap, extrapolate), and the documentation must state that neither meets the full need of a subsystem that asks for more than the baseline sends.
    • 2026-10-27: the section on the author's earlier presentations is left out of v0.1.0 until the titles are verified.
    • 2026-10-27: the counting model is approved, with the caveats that "one test per dependency" is arbitrary and that n counts baseline data elements, not baseline systems.
