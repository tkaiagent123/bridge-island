# Security policy

bridge-island is a simulation and teaching tool. It is not flight, medical or
safety software and is not certified for any operational use.

If you find a vulnerability (for example in the YAML code generator or the
release scripts), report it privately through GitHub's "Report a vulnerability"
feature on this repository's Security tab. Do not open a public issue.
I aim to acknowledge reports within 14 days.

Supported versions: the latest release only.
