# AI usage disclosure

This project was developed with an AI coding assistant. This page records what was used,
where, and the state of the author's review. The author, Tzvi Kaminsky, directs the work and
is responsible for its content.

## Tools and models

| Item | Name and version | Provider |
| --- | --- | --- |
| Coding agent | Claude Code 2.1.311 (command-line) | Anthropic |
| Language model | Claude Sonnet 5.5 (model ID `claude-sonnet-5-5`) | Anthropic |
| Web search and page fetch | The tools built into Claude Code, used only to look up public references | Anthropic |

No other AI tool or model was used. Dates of use: 2026-10-25 to 2026-10-27. The agent ran on
the author's machine, wrote files in the repository, ran the tests and linters, and created
the git commits under the author's git identity.

## What came from the author, and what from the assistant

**From the author, not generated:** the bridge/island architecture, its vocabulary, the six
design guidelines (G1 to G6), the choice of examples and experiments, and every decision
recorded in the review column below.

**Generated by the assistant:** the Python implementation, the tests, the documentation text,
the build and CI configuration, and the choice of every invented name, field, rate and number
in the examples. No code or text was copied from another project. The public references in
`docs/related-work.md` were looked up against their public pages by the assistant using web
search and fetch; the author has not yet verified them independently.
